# Security Policy

We take security seriously and appreciate responsible disclosure.

## Reporting a Vulnerability

If you discover a security issue, please report it privately:

- **Email:** akshay2642005@gmail.com
- **Subject:** `Security Issue: rust-tanstack-starter`

Please include:
- A clear description of the issue
- Steps to reproduce
- Affected versions/branches
- Any known mitigations or workarounds

> **Do not** open a public issue for security-related reports.

## Response Timeline

We aim to follow this timeline:

- **Acknowledgement:** within 48 hours
- **Initial assessment:** within 5 business days
- **Status updates:** at least every 7 days until resolved
- **Fix and disclosure:** as soon as a patch is available

## Supported Versions

Security fixes are provided for:

- The `main` branch
- The latest released version (if applicable)

Older versions may not receive security patches.

## Security Best Practices

When contributing:
- Avoid committing secrets (API keys, tokens, credentials)
- Use environment variables and `.env` files for secrets
- Follow least-privilege principles

Thank you for helping keep this project secure.
